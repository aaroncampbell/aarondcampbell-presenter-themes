Private Presenter themes and presentation customizations for AaronDCampbell.com.

== Description ==

This site-specific companion plugin provides AaronDCampbell.com themes and
presentation customizations for Presenter. It is installed and distributed
separately and is never packaged with the public Presenter plugin.

== Installation ==

Install and activate Presenter first, then install and activate this plugin.
